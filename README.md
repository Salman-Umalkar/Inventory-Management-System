# Inventory-Management-System

An Excel-based Inventory Management System used to manage products, customers, vendors, purchases, sales, and stock levels.

## Features
- Dashboard with key business metrics
- Customer and vendor management
- Purchase and sales tracking
- Stock level monitoring
- Profit and loss summary
- Low-stock and reorder notifications
- Charts for products, customers, and inventory

## Tool Used
- Microsoft Excel

## Project Purpose
This project helps organize inventory data, track stock movement, monitor transactions, and make inventory management easier.
